Servidor web con sockets

Esta página fue servida por FileHttpServer, un servidor escrito con ServerSocket que atiende peticiones consecutivas (no concurrentes).

Recursos servidos

Cada elemento de esta página es una petición HTTP distinta, atendida una tras otra por el mismo servidor:

  • /index.html — este documento (text/html)
  • /styles.css — la hoja de estilos (text/css)
  • /logo.png — la imagen de abajo (image/png, binaria)

Imagen

Si la imagen se ve, el servidor está copiando bytes binarios correctamente y enviando el Content-Type adecuado.

Pruebas rápidas

  • /pagina2.html — segunda página, para comprobar varias peticiones
  • /logo.png — la imagen servida directamente
  • /no-existe.html — debe responder 404
